# 🎯 AD Strategy Optimizer

AI-powered tool untuk generate winning ads strategy, monitoring Excel, dan MCP-ready prompt.

## Features

✅ **Smart Prompt Generation** - Output siap paste ke Claude dengan ads platform  
✅ **Excel Monitoring** - Track all metrics automatically dengan formulas  
✅ **Historical Data Learning** - AI belajar dari previous campaigns untuk recommendation lebih akurat  
✅ **14-Day Testing Roadmap** - Day-by-day actions dengan decision points  
✅ **Winning Ads Prediction** - Confidence-based recommendations  
✅ **Multi-Platform Support** - TikTok, Facebook, Anthropic, atau multi-platform  

## Quick Start

### 1. Local Development
```bash
git clone <repo-url>
cd netlify-ads-optimizer
open index.html
```

### 2. Deploy to Netlify
```bash
# Via CLI
netlify deploy

# Via Netlify web UI
1. Connect GitHub repo
2. Set build command: (none, static site)
3. Set publish directory: . (root)
4. Deploy!
```

### 3. Usage

**Step 1:** Fill the form with:
- Previous campaign data (if available)
- Product/business context
- Platform & goals
- Testing preferences

**Step 2:** Click "Generate Strategy"

**Step 3:** Get three outputs:
- 📋 Claude prompt (copy & paste to Claude)
- 📊 Excel monitoring sheet (download & track)
- 🔄 JSON data (for MCP integration)
